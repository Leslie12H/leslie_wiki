# 对话调优需要按动作证明而非固定步骤放行

## 隔离复验的配置生效与旧草稿权威

2026-10-21 的续接记录见 Maxwell output/evolve-unified-20261019/flexibility-implementation-20261020.md 与 flexibility-final-review-20261021.md。

**Why:** 仓库通用 Prompt 已修改不代表共享预设或已有 Thread 已加载。只复制预设的工具和模型，却换成未配置必要目录的本地后端，会在 Runtime 接纳前失败；不能据此评价模型能力或记为评测 Trial。解析出的完整资源清单被模型缩短后，旧 baselineHash 不再证明这份内容。新会话读到旧草稿，也可能把旧文案当成比当前服务端状态更高的权威。

**How to apply:** 对齐实际 Preset/Prompt、后端、技能和工具目录，使用独立副本验证通用产品改动，不改共享被测对象或注入专用成功提示。原任务续接保留同一预算根；区分新会话与新任务。基线完整性校验应复用到保存、确认和直接/草稿冻结入口，候选变体仍按其真实改动语义检查。错误诊断只报告可证明动作分支的契约字段；历史目录存在其它重复标签时，不能猜当前有多种形状的动作，更不能放宽执行校验。普通业务纠错后仍无实际资产，就保留失败，不把复述、模型结束或回归通过称为候选生成成功。

2026-10-20 用户要求完整检查历史评测进入、资料引用、目标修订、候选生成、真实验证、比较与采纳，避免逐步试跑才暴露后续限制。

**Why:** 物理 Work 归属、来源题集、实际诊断范围、目标草稿与正式修订、传输执行器、持续模式的单资源 Method 和隐藏验收政策若各自成为硬门槛，会产生互相矛盾的准入。合法采用 Artifact 不自动解决 Case 正文可读；未记录版本也不等于历史快照不存在。一次静态检查同样不能证明远端未来执行必然成功。

**How to apply:** 以完整调用链为范围，区分可直接复用的历史基线、待补证据及已证明必要的补跑。Agent 自主选择资料和动作，平台保留业务/hidden隔离、精确冻结证据、同根预算、幂等恢复与正式采纳权限；检查绑定到动作，不把方法库或本次验收门槛写成所有任务的固定流程。发送前失败与已发送结果未知分别处理，不通过换键重试解除未知保护。性能审查保留短锁、有界热状态及按需历史原件，不能靠扩容或多建表绕过。

当前审查快照、逐项源码、技术复现、拟变更面和一次性验收矩阵查 Maxwell 本地 output/evolve-unified-20261019/full-flexibility-review-20261020.md；真实执行/环境恢复查同目录 dev-tuning-20261020.md。本文不保存易变的缺陷数、Run/Grant ID或发布状态，不推断整改已完成。


## 授权查询与预算锁的性能边界

2026-10-21 的隔离 PostgreSQL 回归发现：带递归血缘、成员与可见性校验的复杂 SQL，在小规模索引读取上也可能主要耗时于 JIT 编译；扩大 statement timeout 不能解决用户等待和持锁成本。

**Why:** 逻辑上有界的返回条数不等于规划/编译有界；若在预算或资产发布锁内编译复杂授权表达式，会把计算开销放大为并发等待。将整包测试连接全局关闭 JIT 只能作为定位对照，不能替代产品实现验证。

**How to apply:** 先对照默认设置与仅测试连接关闭 JIT，保留实际查询计划、完整权限负例及锁延时。相关授权操作可采用短事务内 SET LOCAL jit=off，读操作保持只读，结束后回滚/提交并确认设置不泄漏到池连接；不要修改数据库全局默认或放宽权限 SQL。恢复读优先 Search 精确基线，发现读只查询 ID，禁止为选一个基线加载整段 Run 历史 JSON。具体代码和本轮证据查 Maxwell output/evolve-unified-20261019/flexibility-implementation-20261020.md，不把实验数字当 dev SLA 或真实候选验收结论。


## 工具契约投影、错误反馈与引用读取

2026-10-21 的真实隔离对话补充了模型适配与资料引用两项核查方法；具体会话、错误与修复验证均查 Maxwell output/evolve-unified-20261019/flexibility-implementation-20261020.md，不在本文保存易变模型、会话ID或验收状态。

**Why:** 合法的工具执行JSON Schema不一定可直接提交模型。重复action标签会阻断判别联合的模型投影，历史持久目录又可能保留旧形状；仅刷新远端实现不足以证明旧会话恢复。通用匿名oneOf错误不能帮助Agent修正缺失必填字段。引用的Case ID只证明来源，不等于授权读取原始Case；脱敏复制件的artifactRef才是分析材料的读取入口。

**How to apply:** 对当前真实工具目录和历史持久形状分别测试模型投影，保持原始执行Schema与权限校验不变；多参数形式归于一个action并保留互斥规则，不能靠去掉服务端校验过关。校验失败可在已证明的动作分支报告缺失字段名，不回显参数值，也不猜测分支。自然用户验收中保留模型错误、占位输出与错误读取路径，不能将材料已保存、工具调用或模型完成等同于资料已阅读及候选有效；若切换模型或改用技术路径，单独记录其边界。

## 历史存在性检查与辅助诊断边界

2026-10-21 继续复查预算锁内的基线重试守卫：即使不读JSON，逐行取回全部Run/Attempt元数据也会随历史放大锁窗口。具体实现、默认JIT全包、SQL与领域状态逐项对照及真实验收边界查 Maxwell output/evolve-unified-20261019/flexibility-final-review-20261021.md。

**Why:** 只需判断是否有危险历史时，搬回整段元数据没有业务收益；资料元数据读取成功不代表正文读取，模型收到明确工具参数后读到正文也不能修正原自然场景的失败。

**How to apply:** 用EXISTS检查存在性，保留未确认取消与未知派发的阻断条件，逐状态对照领域规则，覆盖NULL、未知状态及远端绑定。自然对话、内部参数引导的辅助诊断与实际质量测量分别记账；新自然复验使用未受提示污染的会话，不把技术通道可达称为调优闭环或有效提升。


## 原件读取、确认门禁与受限模型诊断

2026-10-21 的续接诊断与补充接口确认查 Maxwell output/evolve-unified-20261019/flexibility-implementation-20261020.md、flexibility-final-review-20261021.md 及 continue-tuning-confirmation-20261021.md；不在知识库保存临时模型、进程、密钥或 Run 状态。

**Why:** Skill 注册行存在但源文件不在隔离环境时，业务接口仍可返回文件不存在；把它当成缺权限会引导无必要的扩权。文件工具的 Permission denied 也不等于 EVOLVE 业务授权失败。草稿写入、确认和冻结是不同状态，若确认没有执行冻结所需的结构与精确资料检查，就会把不可用内容确认为正式意图。准备阶段的 intent 转换限制同样可能成为隐藏的固定执行顺序。

**How to apply:** 对照精确 Preset 引用、注册元数据和同一 Key 在原服务/隔离服务的真实响应，只补获准冻结资源闭包并记录文件哈希，不删 Skill、不扩大权限。业务权限提示限定于可证明的业务工具错误。确认阶段复用冻结的结构和有界只读资料校验；保留历史已确认记录，修订产生新版本。阶段转换仅沿原 Work 做 CAS，保留预算根、资产和历史，不将转换本身视为派发许可。模型调用按精确 Run 的持久审计事件累计，不以某类事件未进入 SSE 推断没有调用；预留停止余量、回读原配置恢复，模型更换不等于真实候选达标。界面遗漏瞬时终态时可按现有 Chat 模式低频核对检查点，仅活动可见会话读取，避免轮询完整历史。

## 审阅对象映射、冻结身份与主线整合

2026-10-21 的续接与实际页面证据见 Maxwell output/evolve-unified-20261019/flexibility-implementation-20261020.md；配置、迁移和回归结果以该执行记录为准。

**Why:** 草稿内部名称与领域名字可能不一致，展示层若凭名称猜测，能把对象说明与基线变体的审阅入口对调；一个旧空草稿也可能遮挡其它独立的合法待审项。Artifact内容哈希、基线库存哈希和草稿正文哈希证明不同身份，不能互换。旧工作区整合新main后，模型模块边界、独立配置资产归属与已移除的配置形状也可能变化。

**How to apply:** 从后端规范化的对象→Artifact种类映射核对整条页面审阅路径，测试同屏不同类型草稿与精确冻结引用；独立草稿允许分别审阅，局部就绪不称整体可启动。运行计划使用授权元数据中的精确Artifact ID与内容Hash，错误只指出可验证缺项，不让模型反复重确认已冻结内容。整合新main时保留原改动恢复点，重新生成契约并运行相关完整回归；配置不兼容和隔离迁移按其实际范围单独确认，不把配置迁移当成被测模型变更。自动化恢复fixture不依赖主机与数据库时钟恰好一致；单次claim失败先复现，不凭逻辑用量日志断言预算预留丢失。技术前置补齐与Agent自然场景表现分别记录，不覆盖原失败。
