# EVOLVE 页面清晰度与核心能力位置

2026-10-13 用户在本地页面设计迭代中明确纠正：用例和评分是核心能力；不要泛化的 AI 式提示文案；不要以多个独立块切碎页面。用户进一步指出，问题是“一点都不清晰”，不是功能复杂。

**Why:** 仅删除卡片、缩减信息或调整视觉风格，不能解决对象、关系、当前状态与操作不清楚的问题。将用例与评分归为辅助资源，会错误表达其产品地位。

**How to apply:** 先核对用户在页面里操作的具体对象和与其他对象的关系，再排布页面。列表应显示可识别的对象名称；规则、结果和决定应有明确归属；关联对象应能直接进入。提示仅用于当前操作需要的信息，不写设计说明或价值口号。检查完整页面和实际点击路径，不能只看单张卡片。

用户进一步要求先画清用例、评分、基准、评测和调优的关系及完整操作流程，不再只调整入口和文案。关系图、操作图、问题分流与源码核对见 `/Users/leslie/Downloads/sandai-code/maxwell-ai/output/evolve-model-and-workflow-20261013.md`。

**Why:** 历史方案要求不等于当前实现。普通新运行采用最新关联资产的设计要求，必须与当前启动入口取冻结 Benchmark 组合的实际语义区分；只展示版本名称无法解释何时生效。

**How to apply:** 从该文档的代码指针重新核对资产修订、基准版本与 Run 快照。分别画清修用例、修评分后重评原证据、改 Agent 后重新执行，以及候选产生、采纳、实际应用和回归验证。图中的目标流程与已验证能力分别标明，不能以页面可点击证明完整自动闭环。

## 2026-10-14 目录身份与失败状态

Benchmark / 评测记录列表的实现、截图和浏览器验证见[列表布局记录](/Users/leslie/Downloads/sandai-code/maxwell-ai/output/evolve-catalog-layout-20261014.md)；通用平台的执行连接与被测对象是独立身份。

**Why:** 按连接名称筛选不能把 executorRef 填进 targetRef；读取目录失败也不等于连接已删除。把运行 completed 表述为评分通过，或从一页记录推测总成绩，会把导航展示变成错误结论。

**How to apply:** 复用生成客户端与元数据目录，连接按准确身份匹配名称；技术标识按需展开，保留独立对象筛选和返回上下文。目录读取失败不阻断已可读取的记录，主列表失败收敛成一处可恢复提示。验证更换筛选重置游标、返回保留筛选、空/错/长内容和窄屏操作；UI 夹具与真实评分验收分开记，当前实现及运行环境仅查上述记录。


## 2026-10-14 调优基线与候选复测

实现范围、差异、截图及交互验证见[调优与候选复测记录](/Users/leslie/Downloads/sandai-code/maxwell-ai/output/evolve-tuning-flow-ui-20261014.md)。

**Why:** 当前目录名称可能已经变化，不能借它描述历史 Run 的冻结输入。工作台顶部常驻大块配置会压缩对话区域；创建复测记录也不能证明候选已实际应用。

**How to apply:** 先展示来源时间、实际对象版本、每题次数与冻结规则含义，精确引用按需展开。任务顶部保留紧凑摘要，复测入口提供完整确认；配置读取失败不能猜测执行方式。重试验证同一请求身份，离开与返回验证草稿和基线不丢失；实际应用以执行回执为准。组件夹具的交互、模拟提交与真实 Agent / Judge 验收分别记录。


## 2026-10-14 直接评测入口与失败选择

运行表单的布局、状态保护、专项回归和浏览器证据见[直接评测入口记录](/Users/leslie/Downloads/sandai-code/maxwell-ai/output/evolve-direct-run-entry-review-20261014.md)。

**Why:** 执行连接不等于服务内的具体被测对象；历史被测配置也不等于历史用例与评分组合。界面混用名称会让用户误判运行范围。选择新版本失败时保留旧选择虽然方便恢复，但直接允许提交会让用户误测旧版本。

**How to apply:** 分别呈现连接、必要的对象标识、被测版本和本次评测标准。失败替换保留旧数据，同时阻止提交，直到重试成功或用户明确继续使用旧选择。UI 与 Store 使用同一就绪状态，返回与分页保留选择；未知提交结果沿用同一幂等身份重试。技术引用折叠，运行回执才是实际应用依据；组件模拟响应不算真实评分。


## 2026-10-14 接入登记与检查恢复

接入表单、预填声明、检查状态恢复与布局证据见[接入表单记录](/Users/leslie/Downloads/sandai-code/maxwell-ai/output/evolve-executor-entry-review-20261014.md)。

**Why:** 登记保存、检查进行中和读取检查状态失败是不同事实。把读取失败显示为仍在检查，或将没有报告显示为等待，会让用户反复登记；丢掉 Agent 草稿里的能力声明也会造成连接信息与后续执行预期不一致。

**How to apply:** 保存事实独立呈现，错误保留可读原因，提供只读刷新和管理入口；新检查期间不显示旧通过结论，无报告不推断正在运行。完整传递已有草稿，专属字段仅用于当前执行方式，校验后才提交；保存时防止新编辑被旧响应清空。连接通过、模拟组件提交和真实评分分别验收，实现与环境状态只查记录。
