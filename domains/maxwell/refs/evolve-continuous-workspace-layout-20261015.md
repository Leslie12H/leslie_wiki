# EVOLVE 整体工作区布局约束

2026-10-15，用户明确否定把指标、列表和详情分别装入独立面板的第一版布局，要求仔细学习 LangSmith 与 Opik 的整体性页面。规划的修正说明及本轮截图见[统一展示规划](/Users/leslie/Downloads/sandai-code/maxwell-ai/output/evolve-unified-ia-plan-20261015/README.md)。第一版未获认可；修订版仍是待评价的示例布局，不是真实业务或实施验收。

**Why:** 多个独立外框、重复内边距和面板间空隙会把同一次选择对应的趋势、列表与证据割裂。仅复用品牌颜色并不能形成整体工作区。

**How to apply:** 让上下文、工具栏、表格和选中详情共享页面底色、边缘与选择状态，使用必要的横纵分隔组织内容。图表融入主区，列表与详情紧密相接；对象节点的关系表达保留，但不把每一段信息都封成卡片。继续保留暖色、明确导航和可阅读的原件，后续方案需重新核对用户对实际整页的评价。

本轮只调整独立布局预览，未改 Studio 业务代码或数据。截图及预览状态应回到规划记录核对，不从本条指针推断方案已经批准。
