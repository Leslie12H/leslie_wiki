# Testing(测试职业知识)

> 跨业务通用的测试方法论、框架经验、用例设计。与具体业务无关的测试知识都放这里。
> 业务专属的测试资产放对应 `domains/<biz>/`(如 [vidmuse testing](../../domains/vidmuse/systems/testing.md))。

## 可能的 page 类型
- 测试框架的使用约定与坑(pytest / playwright / 自研框架)
- 用例设计方法(边界、等价类、状态机、组合)
- 自动化测试的稳定性经验(flaky 处理、重试、隔离)
- 测试数据 / 环境管理
- 性能 / 压测 / 混沌
